# 两只猫的饭点 —— 自己托管版

同一个页面，但**不依赖任何人的服务器**。放到你自己的 GitHub 上，
网址是你的，文件是你的，Claude 那边就算全没了也不影响。

带云同步：手机和电脑同一份，数据存进**你自己的私有仓库**，不经过任何第三方数据库。

---

## 第一步 · 把页面放上去（五步，全在网页上点，不用装东西）

1. 打开 <https://github.com/new>，仓库名填 `catfeed`，选 **Public**，`Create repository`
2. 新仓库页面上点 **uploading an existing file**
3. 把这个文件夹里的 **5 个文件**全拖进去（`index.html`、`sw.js`、
   `manifest.webmanifest`、`icon-180.png`、`icon-512.png`），`Commit changes`
4. 仓库顶部 **Settings → Pages**，`Source` 选 **Deploy from a branch**，
   分支选 `main`、目录选 `/ (root)`，`Save`
5. 等一两分钟，刷新那一页，上面会出现网址：
   `https://<你的用户名>.github.io/catfeed/`

> 这个仓库必须是 **Public**，GitHub Pages 免费版只给公开仓库用。
> 页面里没有任何账号密码，公开不要紧 —— **记录不在这个仓库里**。

## 第二步 · 装到 iPhone 主屏幕

用 **Safari** 打开上面那个网址 → 底部**分享**按钮 → **添加到主屏幕**。

出来就是个爪印图标，点开**全屏、没有地址栏**，跟 app 一样。
断网也能开（页面本身缓存在手机上）。

安卓一样：Chrome 打开 → 菜单 → **添加到主屏幕 / 安装应用**。

## 第三步 · 云同步（想手机电脑同一份就做，不做也能用）

页面里往下翻到「**云同步 · 手机电脑同一份**」那张卡，点开里面的
「第一次怎么设」，照着做就行。要点：

1. 再建一个仓库 `catfeed-data`，这个选 **Private**（记录放这儿，不能公开），
   勾上 `Add a README file`
2. 去 **github.com/settings/personal-access-tokens** 建一把
   **Fine-grained token**：
   - Expiration 选 **No expiration**
   - Repository access 选 **Only select repositories**，只勾 `catfeed-data`
   - Permissions → Repository permissions → **Contents** 改成 **Read and write**
3. 回页面填 `你的用户名/catfeed-data` + 那串令牌，点连接
4. 另一台设备打开同一个网址，填一样的两样东西

**令牌只存在当前这台设备的浏览器里**，不进页面代码、不进那个公开仓库、
也不进导出的 JSON 备份。手机丢了就去 GitHub 点 Revoke，钥匙当场作废。

同步是**按天合并**的：两台设备各记各的，谁也不会把谁抹掉；
同一天两边都动过，以最后改的那次为准；健康记事只加不减。
每同步一次就是仓库里的一次 commit —— **所以每一天的每个版本都翻得回去**。

## 跟 Claude 那一版有什么不一样

|  | Claude 那版 | 这一版 |
|---|---|---|
| 网址 | claude.ai 的链接 | 你自己的 |
| 要登录 | 要 | **不要** |
| 手机电脑同步 | 有，自动 | 有，**连一次 GitHub 之后自动** |
| 数据存在哪 | Claude 的云端 | **你自己的私有仓库 + 本机** |
| 历史版本 | 没有 | **有，每次同步一个存档** |
| 离线可用 | 不行 | **行** |

> **两版之间别来回换着用**，会变成两份各自长大的记录。
> 真要搬：一边点「导出备份（JSON）」，另一边点「从备份恢复」。记录是**合并**的，不会删东西。

## 备份还是要做

接通云同步之后，你已经有两份了（本机 + 私有仓库），比之前稳得多。
但页面底部「记录」卡里的 **导出备份（JSON）** 还是**每年点一次**存到自己的硬盘或网盘 ——
任何在线的东西都不该是唯一一份。

## 改动同步逻辑之前，先跑测试

仓库里有个 `tests/` 目录，一条命令跑完：

```
node tests/run.js
```

管的是「改坏了不报错」那一类事故 —— 数据悄悄少一天、令牌悄悄漏进备份、
每开一次页面白记一次 commit。**动任何跟云同步有关的代码，改之前和改之后各跑一遍。**
里面有一条是从真事故来的，`tests/README.md` 写了前因后果。

## 以后要改内容

在 `catfeed` 仓库里点开 `index.html` → 铅笔图标 → 改 → `Commit changes`，
一两分钟后网址上就是新的。手机上那个图标不用重装。

改完手机还是旧的？在 app 里下拉刷新一次（实在不行删掉图标重新添加）。
